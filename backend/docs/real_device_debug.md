# 真机联调排查清单

## ① 手机浏览器打开 http://<lan_ip>:8000/api/health
失败说明：打不开说明网络或防火墙问题，不是小程序的问题。

## ② 核对 config.js 的 lan_ip 与电脑 ipconfig 的 IPv4
失败说明：两者不一致说明小程序指向了错误地址，把 lan_ip 改成电脑的 IPv4。

## ③ 后端是否 0.0.0.0 监听：netstat -ano | findstr :8000
失败说明：只看到 127.0.0.1 说明后端只接受本机连接，手机连不进来，要用 start_server.bat 以 0.0.0.0 启动。

## ④ Windows 防火墙是否拦了 8000 端口
本机实测：Domain 开、Private 关、Public 开；当前网络位置 TP-LINK_3529（WLAN）类别为“公用”，
所以手机从局域网进来的 8000 端口请求会被公用配置文件的防火墙拦掉。
两种解法（均需管理员）：
  a. 把网络位置改成专用：设置 → 网络和 Internet → WLAN → TP-LINK_3529 → 网络配置文件选“专用”；
  b. 运行 scripts/firewall_allow_8000.bat 放行 8000 端口入站。
验证：手机浏览器打开 http://<lan_ip>:8000/api/health，看到 {"status":"ok","db":"ok"} 即通。

## ⑤ 手机与电脑是否同一网段
失败说明：校园网或公共 WiFi 常有 AP 隔离，手机访问不到电脑；改用手机热点再试一次。

---

真机 http 还需要在手机微信预览页右上角「…」→「打开调试」才放行，否则请求一律被拦。
