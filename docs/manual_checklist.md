# 答辩前人工验收清单

自动化只能覆盖后端接口；小程序端（微信开发者工具）本机 CLI service port 关闭，无法用脚本驱动，按下面清单人工确认。每条照做后勾选。

前提：开发者工具需勾选「不校验合法域名」，否则本机自签 HTTPS 证书会被拦；真机预览必须换成已备案域名 + 正式证书，自签证书不行。
